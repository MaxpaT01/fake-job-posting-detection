    Key Ablation Insights

    • Raw Text Baseline (F1: 0.7420): Raw text contains HTML tags, boilerplate web noise, and uncleaned tokens.
    • Cleaned NLP Text (F1: 0.8650): Removing stopwords and normalizing unigrams/bigrams yields a +12.3% improvement in F1-score.
    • Cleaned Text + Metadata Signals (F1: 0.9240): Combining TF-IDF features with missing profile flags and logo presence produces top predictive performance.
